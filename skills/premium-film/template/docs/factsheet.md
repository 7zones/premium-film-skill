|---|---|---|---|---|---|
| 1 | | VERIFIED / SINGLE-SOURCE / SELF-REPORTED / UNVERIFIED | | | |

Status: VERIFIED = two independent sources or one official primary source; SINGLE-SOURCE; SELF-REPORTED = the organisation's own claim (attribute it: "according to …", "an estimated …"); UNVERIFIED = leave it out. Never upgrade a self-claim. Prefer "can"/"up to"/"an estimated" when the evidence is an average or a plan.
